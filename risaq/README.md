# رِسَاق (RISAQ) — منصة التدريب السيبراني

MVP لمنصة تدريب سيبراني تفاعلية: مصادقة، لوحة تحكم، ثلاثة مختبرات تفاعلية،
نظام نقاط وشارات، وتقرير جاهزية متعدد الأبعاد. هذا المجلد مستقل تماماً عن
تطبيق Next.js الموجود في جذر المستودع (دِثار) ولا يتشارك معه أي كود أو قاعدة
بيانات.

**Stack:** React (Vite) + Tailwind CSS · Node.js/Express · MongoDB (Mongoose) · JWT auth.

## البنية

```
risaq/
  backend/    Express API (auth, labs, scoring, reports, leaderboard)
  frontend/   React SPA (RTL, dark cyber theme)
```

## التشغيل محلياً

### المتطلبات المسبقة

- Node.js 18+
- MongoDB يعمل محلياً على `mongodb://127.0.0.1:27017` (أو أي رابط Atlas) —
  أو، للتجربة السريعة بلا أي تثبيت، ضع `MONGODB_URI=memory` (انظر أدناه).

### 1) الـ Backend

```bash
cd risaq/backend
cp .env.example .env      # عدّل MONGODB_URI و JWT_SECRET عند الحاجة
npm install
npm run seed               # يزرع المختبرات الثلاثة في قاعدة البيانات (تخطَّ هذه الخطوة في وضع memory)
npm run dev                 # يشغّل الـ API على http://localhost:5000
```

**لا تملك MongoDB مثبّتاً؟** اضبط `MONGODB_URI=memory` في `.env` بدلاً من رابط
اتصال حقيقي. يشغّل الخادم عندها مخزناً داخل الذاكرة (in-memory) ويزرع
المختبرات تلقائياً عند الإقلاع — مثالي لتجربة المنصة خلال دقائق، لكن كل
البيانات (الحسابات، النقاط، المحاولات) تُفقد عند إعادة تشغيل الخادم. لأي
استخدام فعلي استخدم قاعدة بيانات MongoDB حقيقية.

### 2) الـ Frontend

```bash
cd risaq/frontend
cp .env.example .env       # VITE_API_URL يشير افتراضياً إلى http://localhost:5000/api
npm install
npm run dev                 # يفتح الواجهة على http://localhost:5173
```

افتح `http://localhost:5173`، أنشئ حساباً جديداً، وابدأ أول مختبر.

## المميزات المُنفَّذة في هذا الإصدار

- **Authentication**: تسجيل / دخول بـ JWT + bcrypt.
- **Dashboard**: نقاط، شارات، مؤشر الجاهزية الإجمالي، أحدث الأنشطة.
- **3 مختبرات تفاعلية** (نفس محرك اللعب يخدم الجميع من بيانات فقط):
  - اكتشاف التصيد الإلكتروني (Phishing Detection)
  - تحليل البرمجيات الخبيثة (Malware Analysis)
  - الدفاع عن الشبكة (Network Defense)
  
  كل مختبر: مؤقّت، تصنيف سيناريو + اختيار مؤشرات (IOCs)، تصحيح فوري من
  الخادم (مفتاح الإجابة لا يُرسل للمتصفح قبل التسليم)، وشرح تفصيلي بعد الإرسال.
- **نظام النقاط والشارات**: نقاط تُحتسب من الدرجة + مكافآت السرعة والمحاولة
  الأولى، وخمس شارات تُمنح تلقائياً حسب الأداء.
- **تقرير الجاهزية**: تفصيل حسب 8 أبعاد جاهزية (تُحسب فقط للأبعاد التي
  دُرِّب عليها المستخدم فعلياً)، توصيات لأضعف بُعدين، وسجلّ كامل للمحاولات.
- **لوحة المتصدرين**: ترتيب حسب النقاط.

## إضافة مختبر جديد

المختبرات بيانات بالكامل — لا حاجة لكتابة كود جديد. أضف كائناً جديداً في
`backend/src/data/labs.js` بنفس شكل المختبرات الحالية (items بها facts،
options للتصنيف، iocOptions اختيارية، ومفتاح الإجابة)، ثم شغّل `npm run seed`.
سيظهر تلقائياً في الواجهة عبر نفس مكوّن `LabRunner`.

## ما لم يُبنَ بعد (خارج نطاق هذا الإصدار)

الوثيقة الأصلية تصف منصة أوسع بكثير (خصم ذكي تكيّفي، بصمة سلوكية عبر ML،
وضع ضغط بأحداث متزامنة، محاكي "ماذا لو"، مساعد AI حواري). هذا الإصدار يبني
الأساس الكامل (auth + labs engine + gamification + reports) بحيث يمكن إضافة
هذه الطبقات لاحقاً كخدمات إضافية فوق نفس البيانات (Attempt records تحمل
already itemResults تفصيلية تكفي كمدخل لأي تحليل سلوكي لاحق).
