# نَجا NAJA

موقع ومنصة عرض تفاعلية لمبادرة نَجا (NAJA): منظومة ذكية لجاهزية إمداد الدم والاستجابة للحالات الحرجة. جاهزية تسبق الحاجة.

## التشغيل

```bash
npm install
npm run dev      # يفتح الموقع محلياً
npm run build    # ينتج نسخة جاهزة للنشر في مجلد dist
```

## الاستمرار في Claude Code

افتح الطرفية داخل هذا المجلد واكتب `claude`. ملف `CLAUDE.md` يشرح المشروع وقواعده، فيقرأه Claude Code تلقائياً.

أمثلة لطلبات:
- "أضف صفحة لفريق العمل بالأسماء التالية…"
- "غيّر لون التمييز إلى …"
- "انشر الموقع على Vercel"

## النشر

مجلد `dist` بعد البناء موقع ثابت يُرفع كما هو على Vercel أو Netlify أو GitHub Pages.

> كل البيانات في الجداول واللوحة اصطناعية للعرض.
